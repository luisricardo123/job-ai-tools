# Angular 20 — Índice

Proyecto **standalone-first** con signals estables como modelo de reactividad principal. Abre solo
el archivo del área que toca la tarea:

| Archivo | Cuándo abrirlo |
|---|---|
| [`arquitectura.md`](arquitectura.md) | Al organizar carpetas, bootstrap de la app o providers globales. |
| [`componentes.md`](componentes.md) | Al crear/editar un componente: `input()`/`output()`/`model()`, queries, DI. |
| [`templates.md`](templates.md) | Al escribir o revisar el HTML de un componente (control flow, `@defer`). |
| [`reactividad.md`](reactividad.md) | Al manejar estado con signals, `computed()`, `effect()` o change detection. |
| [`forms-routing.md`](forms-routing.md) | Al crear formularios reactivos o rutas/guards funcionales. |
| [`testing.md`](testing.md) | Al escribir el spec (`*.spec.ts`) de cualquiera de los anteriores. |

Las convenciones comunes a ambas versiones (naming, estructura por feature, etc.) están en el
[`SKILL.md`](../../SKILL.md) raíz, no repetidas aquí.
