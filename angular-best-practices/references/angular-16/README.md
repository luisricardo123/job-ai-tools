# Angular 16 — Índice

Proyecto típico basado en **NgModules**. Los signals están disponibles y se usan con frecuencia; conviven con RxJS sin reemplazarlo (detalle en [`reactividad.md`](reactividad.md)). Abre solo el archivo del área que toca la tarea:

| Archivo | Cuándo abrirlo |
|---|---|
| [`arquitectura.md`](arquitectura.md) | Al organizar carpetas, módulos o decidir si un componente va standalone. |
| [`componentes.md`](componentes.md) | Al crear/editar un componente: inputs, outputs, queries, change detection, DI. |
| [`templates.md`](templates.md) | Al escribir o revisar el HTML de un componente. |
| [`reactividad.md`](reactividad.md) | Al manejar estado, streams RxJS o desuscripciones. |
| [`forms-routing.md`](forms-routing.md) | Al crear formularios reactivos o rutas/guards. |
| [`testing.md`](testing.md) | Al escribir el spec (`*.spec.ts`) de cualquiera de los anteriores. |

Las convenciones comunes a ambas versiones (naming, estructura por feature, etc.) están en el
[`SKILL.md`](../../SKILL.md) raíz, no repetidas aquí.
